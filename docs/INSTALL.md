# Install DueOra (Android)

📱 *Install DueOra*
1. Open this link on your Android phone and download DueOra:
   https://expo.dev/artifacts/eas/M0hXtJnmaYojV1wPTHJngkhc-HG11HnlVCFnWQT5Iwc.apk
2. When asked, allow your browser to *Install unknown apps*.
3. If Play Protect warns you, tap *More details → Install anyway* (normal for apps not on the Play Store).
4. Open DueOra, create an account, then add your company and bills.

QR code: `docs/install-qr.png` (same link). Install page (once GitHub Pages is on): https://annithah.github.io/dueora/
